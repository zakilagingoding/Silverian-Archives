# 📖 Silverian Archives

Sebuah platform web berbasis Laravel untuk mengelola arsip informasi, database karakter, berita, panduan mekanik, dan lore cerita. 

## 🚀 Fitur Utama

- **Manajemen Pengguna & Peran:** Sistem autentikasi untuk pengguna dan admin.
- **Ensiklopedia Karakter:** Menampilkan detail karakter, elemen, latar belakang cerita (lore), dan daftar peringkat (tier list).
- **Berita & Pengumuman:** Publikasi artikel berita terbaru beserta banner gambar.
- **Mekanik Permainan:** Panduan sistem permainan lengkap dengan tips, FAQ, dan integrasi video YouTube.
- **Sistem Ulasan Komunitas:** Pengguna dapat memberikan ulasan (rating 1-5), menyukai ulasan, dan berkomentar pada halaman karakter.
- **Codex & Lore:** Artikel terstruktur berdasarkan kategori untuk memperluas cerita dunia (world-building).

## 🛠️ Teknologi yang Digunakan

- **Backend:** Laravel (PHP)
- **Database:** MySQL
- **Frontend:** Blade Templating (Tailwind CSS / Bootstrap)

## 📋 Persyaratan Sistem

Pastikan sistem lokal Anda telah menginstal:
- PHP >= 8.1
- Composer
- MySQL / MariaDB
- Node.js & NPM (untuk kompilasi aset frontend)
